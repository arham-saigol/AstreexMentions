13 · Guidelines

Design principles

Rules for extending the system without losing the Astreex character.

Use contrast and hierarchy before adding color. Reserve signal coral for the most important action, selected state, or data highlight in a view.

Always show where a mention came from, who posted it, and when. AI categories organize the conversation; they never replace the original meaning.

Use 120ms for feedback, 220ms for controls, and 420ms for layout changes. Respect reduced motion and never delay access to information.

Loading, empty, partial, permission, rate-limit, offline, and error states are part of the component—not polish added later.

/* Minimum token contract for future components */
:root {
  --component-bg: var(--surface);
  --component-fg: var(--text);
  --component-muted: var(--text-secondary);
  --component-border: var(--line);
  --component-radius: var(--radius-md);
  --component-motion: var(--medium) var(--ease-out);
}

/* Required behavior */
@media (prefers-reduced-motion: reduce) {
  * { transition-duration: 0.01ms; }
}
